# display
0. ssh into pi
1. ```cd``` into frontend folder. ```npm install```
2. Run ```npm run dev -- -H 0.0.0.0```
3. ```cd backend``` 
4. Create venv for packages ```python3 -m venv venv``` and activate ```source venv/bin/activate```
5. ```pip install -r requirements.txt``` to get required packaged for backend
6. run ```python app.py```
7. Open ```http://192.168.1.180:3000/``` on your computer
